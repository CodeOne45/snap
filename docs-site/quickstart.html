Quickstart

Try a shipped example first

snap ships a few ready-made templates under examples/templates/ in the repo — copy one into your local template store to try snap new immediately, with nothing to capture first:

cp -r examples/templates/go-cli-starter ~/.config/snap/templates/
snap new go-cli-starter ~/code/my-cli --var name=my-cli --var module=github.com/you/my-cli

Capture a project of your own

# Preview what would be captured, without writing anything
snap capture ~/code/acme-site --as client-site --dry-run

# Capture non-interactively, accepting every detected candidate
snap capture ~/code/acme-site --as client-site --yes

# Capture interactively: accept, rename, or reject each candidate
snap capture ~/code/acme-site --as client-site

Capture scans the project, builds a list of placeholder candidates (strings that look like the project's own name or other per-project identifiers), and writes a snap.toml manifest alongside the renamed files. It never captures secrets (.env*, *.pem, *.key, id_rsa* are excluded by default).

Inspect what's available

snap list
snap list --json
snap show client-site
snap show client-site --json

Generate a new project

snap new client-site ~/code/northwind-site --var name=northwind-site
snap new client-site ~/code/northwind-site --dry-run
snap new client-site ~/code/northwind-site --yes    # error instead of prompting
snap new client-site ~/code/northwind-site --force  # overwrite an existing non-empty target
snap new client-site ~/code/northwind-site --without docker --with ci

Or skip the flags — use the TUI

snap

Run snap with no arguments to browse templates, fill in variables, toggle optional blocks, preview the generated file tree, and confirm, all interactively.
