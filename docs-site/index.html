snap

Capture existing projects as templates, and generate new projects from them.

snap capture turns a real project into a reusable template: it scans the project, proposes which strings look like the project's own name (or other per-project identifiers), and lets you accept, rename, or reject each one before writing a template manifest. snap new runs the reverse: fill in the template's variables and it renders a brand-new project.

Why

Most "project generator" tools require you to author a template from scratch in some bespoke DSL. snap instead starts from a project you already have working — it detects what should be a variable instead of asking you to mark it up by hand.

Install

git clone https://github.com/CodeOne45/snap
cd snap
make build
./snap --version

Or via a package manager, once a release is published — see the README.

Three ways in

  • CLI — snap capture, snap new, snap list, snap show.
  • TUI — run snap with no arguments for an interactive wizard.
  • MCP server — snap mcp exposes the same use cases to an agent over stdio.

Architecture, in one line

Every command builds an immutable plan (what would be written) before anything is applied; --dry-run and --json both just print that same plan instead of applying it. The CLI, TUI, and MCP server are thin adapters over the same core use cases — no logic is duplicated between them.
